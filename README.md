# Recruitment Agency Automation

Автоматизация обработки входящих кандидатов в Bitrix24 для рекрутингового агентства.

> **Incoming candidate → AI qualification → CRM → SLA → Recruiter → Interview → Decision**

## Задача

При большом количестве входящих кандидатов рекрутеру важно быстро определить, на какую позицию подходит кандидат, создать структурированную CRM-сделку и не потерять первый контакт.

Основной фокус кейса — не интерфейс CRM, а автоматизация рабочего процесса рекрутера.

## Решение

Входящий кандидат проходит через последовательность автоматизированных действий:

1. AI определяет желаемую должность из текста обращения.
2. Создаётся и заполняется CRM-сделка кандидата.
3. Назначается ответственный рекрутер.
4. Формируется SLA первого контакта.
5. Рекрутер получает понятное следующее действие.
6. Кандидат проходит квалификацию, интервью и дальнейшие этапы подбора.

## Что реализовано

- CRM-воронка подбора кандидатов
- AI-определение желаемой должности
- создание и заполнение CRM-сделки
- SLA первого контакта
- автоматическая задача рекрутеру
- контроль срока реакции
- ответственный и следующий шаг
- переход кандидата по этапам подбора
